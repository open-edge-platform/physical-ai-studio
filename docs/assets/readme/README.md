# README demo assets

The Python API and Studio UI GIFs in this directory are generated from [`docs/demos/readme`](../../demos/readme/README.md) with React, Playwright, and FFmpeg. Update the source files there, then run `npm run render`. See the [tooling license notes](../../demos/readme/LICENSES.md) for upstream licenses. The GUI uses the [committed Studio recording](../physical_ai_studio_full_overview.mp4); no separate video download is required.
