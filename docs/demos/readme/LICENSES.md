# Animation tooling and licenses

## Decision

Use the existing React layouts with explicit frame props, Playwright screenshots, and FFmpeg GIF encoding. This stack has no organization-size eligibility rule, paid rendering tier, license key, or hosted-service dependency. The replacement timeline code is authored in this repository; it does not copy Remotion's animation or rendering implementation.

## Alternatives checked

- **Remotion 4.0.528:** its [license](https://github.com/remotion-dev/remotion/blob/v4.0.528/LICENSE.md) limits free use to specified entities, including individuals, for-profit organizations with up to three employees, non-profits, and non-commercial evaluation. Other entities need a Company License. Making its source available does not give every organization unrestricted free use. We removed it rather than assuming eligibility or downgrading to a historical license.
- **Motion Canvas:** a genuine open-source alternative under the [MIT license](https://github.com/motion-canvas/motion-canvas/blob/main/LICENSE). Its [official project description](https://github.com/motion-canvas/motion-canvas#motion-canvas) describes a TypeScript generator-based animation library and editor. It is suitable for new motion-graphics projects, but adopting it here would require rewriting the existing React scene layouts. These two demos need only frame-driven fades, progress bars, and a screen recording, so no replacement animation framework is necessary.

Every npm package in `package-lock.json`, including the TypeScript/type-definition toolchain and optional platform binaries, declares MIT, Apache-2.0, or OFL-1.1. The test suite checks these declarations so a new dependency with different terms requires an explicit review. Package metadata is a guardrail, not a substitute for reviewing upstream license texts.

Open source does not mean no obligations. Keep upstream copyright, license, and notice files when redistributing dependencies, fonts, browser binaries, or FFmpeg. FFmpeg's applicable license depends on its build configuration; check `ffmpeg -L` and do not use a build configured with `--enable-nonfree`. The renderer invokes the installed executable and does not link or redistribute FFmpeg libraries. This directory commits scene source, a dependency lockfile, and generated GIFs, not browser or FFmpeg binaries.

Both GIFs are rendered afresh. The API animation comes from the repository's React scenes. The GUI animation uses the [existing repository screen recording](../../assets/physical_ai_studio_full_overview.mp4), not a previously generated animation or an external stock asset.
