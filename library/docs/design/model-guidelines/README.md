# Model Guidelines

These documents describe how models are evaluated, integrated, and enabled for Intel hardware in Physical AI Studio and Runtime.

## Reading Order

1. Start with [Model Implementation Guidelines](./model-implementation-guidelines.md) for the overall model-support approach and lifecycle.
2. Read the [Reference Checklist](./model-implementation-guidelines-reference.md) when reviewing or implementing a model. It turns the guidance into concrete checks and evidence to collect.
3. Read [Intel Enablement Strategy](./intel-enablement-strategy.md) for the proposed cross-team ownership and investment model for Intel hardware support.

The implementation guidelines define the product process. The reference checklist supports execution, while the Intel enablement strategy provides broader organizational context.
